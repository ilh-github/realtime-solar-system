# 2026-08-26 · 太阳/地球/月球精度方案评估（P1，只读）

## 目的

按 `OPENCODE_HANDOFF.md` P1 要求，比较三条精度路线，供决策。本文档只评估，不改代码。

## 当前基线（已实测，见 analysis-20260826-regression-and-horizons.md）

| 量 | 相对 DE441 误差 |
| --- | ---: |
| 地球日心位置 | 2,006 km（J2000）～7,588 km（2026） |
| 月地矢量 | 5.0–9.2 km |
| 月地距离 | 1.3 km（2026-08-26） |

换算成角度：地球误差 3–11″，月球角误差 1.7–4.7″。作为对照，肉眼分辨率约 60″，页面单像素视场通常远大于 10″。**在可视化与小时级演示目标下，当前误差已低于任何可感知阈值**。

## 方案 A：维持现状，明确标注

- 体积/性能：零开销。
- 许可：无新增依赖。
- 精度：地球数千公里、月球公里级（已实测并有 DE441 对照记录）。
- 深时：±5 万年可用（近似外推 + 历史 ΔT 估计），误差随年代扩大并已记录。
- 结论：满足当前项目目标；唯一成本是把"不是精密星历"的边界持续写清楚（README 已做）。

## 方案 B：全量接入 DE440/DE441（SPICE SPK + 浏览器解析）

### 数据事实（2026-08-26 核实，NAIF 官方目录）

| 内核 | 覆盖 | 体积 |
| --- | --- | ---: |
| de440s.bsp | 1849–2150 | 31 MB |
| de440.bsp | 1550–2650 | 114 MB |
| de441（两分卷） | -13200–17191 | 约 3.0 GB |
| de442/de442s（2025-02 新增） | 同 DE440 系列 | 114/31 MB |

### 许可证（NAIF Rules，2026-08-26 核实）

- 内核：允许任何人下载使用；**未修改的内核允许再分发**；商用免费、无需许可。
- SPICE Toolkit 本体：作为第三方工具的组成部分嵌入模块是允许的；单纯镜像再分发完整 Toolkit 需 NAIF 书面同意。浏览器场景不运行 C Toolkit，只解析内核文件，不受此条约束。
- 需在 ATTRIBUTION 中标注 Caltech/JPL/NAIF 来源与"as-is"免责声明。

### 技术维度

- 离线加载：SPK 是二进制 DAF/SPK Type 2（Chebyshev 多项式系数段），纯 JS 解析器约数百行（DAF 目录 + 二分定位 + 13 阶插值），无现成轻量浏览器库是主流选择；31–114 MB 需进 SW 预缓存或首次访问时提示下载。
- TDB/TT：SPK 记录的是 TDB；TDB−TT 周期项幅值约 1.7 ms，远小于模型误差，可直接把现有 TT JD 当 TDB 用（与 HORIZONS 对照时的既有做法一致），但文档必须写明。
- 参考系：DE440 输出 ICRF 轴；本项目用 J2000 黄道系。ICRF 与 J2000 动力学系差约 0.02″（可忽略），但 ICRF 赤道系 → J2000 黄道系需一次旋转矩阵，且黄道定义（DE440 的 mean ecliptic of J2000 vs VSOP 黄道）有 ~0.1″ 级差异，需固定一个转换并记录。
- 中心天体：SPK 给的是相对太阳系质心（SSB）的位置；日心位置需减去太阳（10 号目标）。现有 `threeBodyStateKm` 合同以日心为原点，需加质心→日心一层。
- 几何/视位置：SPK 是几何位置；光行时/视位置仍需自行加（与现状一致，本项目当前未做视位置，边界不变）。
- 深时：DE440 只覆盖 1550–2650；深时（±5 万年）仍必须回退近似模型——双轨制不可避免。
- 性能：Type 2 插值是 O(1) 查表 + 多项式求值，比现有开普勒牛顿迭代更快，无性能顾虑。
- 体积代价：31 MB（de440s）会让离线包约翻倍；114 MB（de440）在移动端 SW 存储上不现实；3 GB（DE441）不可行。

### 方案 B 结论

全量接入对可视化收益为零（误差已低于感知阈值），成本（体积、双轨制、参考系转换、新解析器维护）最高。**不推荐作为默认**。

## 方案 C：混合——太阳/地球/月球用 de440s，其余保持近似

- 收益：1849–2150 内地球误差 <1 km、月球 <0.01 km 量级；三体合同可升级为"DE440 一致性"。
- 成本：+31 MB 离线资产（约翻倍）、JS SPK 解析器、ICRF→J2000 黄道转换、SSB→日心换算、1849–2150 窗口内外双轨切换与回归矩阵（窗口边界、深时回退、ΔT 交互）。
- 适用条件：仅当项目目标从"可视化"升级为"测量级展示/教育演示精度声明"时才值得。
- 变体（推荐若选 C）：**可选高精度模式**——页面检测本地/用户手动放入的 `de440s.bsp`（如 `./kernels/de440s.bsp`），存在则启用 DE440 管线并显示"DE440 模式"标识，不存在则静默用近似模型。默认用户体验零变化，不强制 31 MB 下载，打包脚本不内置内核（许可允许再分发，但保持源码包轻量）。

## 顺带排除项

- astronomy-engine（MIT，约 116 KB）：±1 arcmin 对 NOVAS/DE405 验证。1 arcmin 在 1 AU 约 43,700 km，月球地心约 112 km——**精度低于当前实现**，只适合轻量替代场景，不构成升级。
- Swiss Ephemeris：AGPL/商业双许可，与本项目 MIT 不兼容，排除。
- 在线 HORIZONS：违反全离线原则，仅作独立对照（已用于验证）。

## 建议

1. **默认维持方案 A**：当前精度对可视化目标过剩，边界声明已完备。
2. 若需要"精密演示"卖点，按方案 C 的可选模式实施：`de440s.bsp` 本地可选加载 + JS Type 2 解析器 + ICRF→黄道转换，默认不下载、不打包内核。
3. 无论选择哪条，README 的"不是 DE440/DE441 精密星历"声明在近似管线上必须保留。
